# SHAQ Daily Oracle Lab

[English](README.md)

SHAQ Daily Oracle Lab 是一套本地金融研究对照工作台：它让受治理的盘前方法读取同一份冻结证据并比较研究记录；它不是实盘交易软件，也不构成投资建议。

结果页先区分**方法修改、模型身份、冻结数据、候选筛选和交易规则**，再比较预测。输入不同或历史资料未记录时会直接标明，不包装成严格的同条件实验。

## 三步完成第一次对照

1. 打开「连接设置」，连接 Codex、Claude Code、官方 API 或 OpenAI 兼容中转站；再登录团队仓库并完成研究数据检查。
2. 在「开始运行」选中两个内置方法，并用同一个模型配置运行。它们会收到同一份冻结证据和候选集合。
3. 在「查看结果」选中两条记录，点击「比较选中版本」。只有模型、冻结数据、候选集合、模拟交易规则和交易日期全部标为相同，差异才能单独解读为方法差异。

## 三页工作台

### 三个模型连接入口，任选一个

- **连接 Codex**：检测可用且已登录的 Codex CLI，再测试结构化返回。只安装聊天 App 不等于完成此连接；参见 [Codex 官方说明](https://learn.chatgpt.com/docs/codex/cli)。
- **连接 Claude Code**：检测 Claude Code CLI 及其登录，Claude 网页／聊天 App 登录并不等同。
- **连接 API**：选 OpenAI／Anthropic 官方协议或兼容中转，填写 HTTPS 服务地址、API Key、准确模型 ID 和支持的上下文长度。只用 API，无需安装两个 CLI。

「修改版本」顶部有「下载」和「上传」两个入口，各自打开应用内多选弹窗并读取团队版本清单。「下载」会禁选本地已有相同内容；「上传」只列出已保存的版本，只有当前账号拥有、完整且远端尚无相同内容的本地版本可选，未保存草稿需先保存。打开弹窗不会发布，确认后逐项传输，失败项可重试而不重复成功项。内容去重不受改名或无关分支提交影响，也不会改写历史运行、账户身份或余额。

中转站的模型 ID、密钥分组／权限与协议必须匹配实时模型广场；展示名称不是接口 ID。错误会显示实际收到的 HTTP 状态、有限的服务代码／信息及请求编号（若有）。仅凭 HTTP 400 不能确定原因，应核对地址、协议、模型和密钥权限，不认定某家服务的具体故障。软件不会偷偷换模型或服务。详见[连接指南](docs/user-guide.md#1-connect-an-analysis-model)。

「今日运行」按纽约时间和 NYSE 日历判断：休市或美东 04:00 前不能启动，香港周一早晨可能仍是美东周日。正常 NYSE 周一在取得当天盘前股票数据后可以运行。若全部股票都缺当天盘前资料，批次在模型分析前停止；空数据只表示「未取得当天盘前数据」，不代表已证明没有成交或接口故障。部分缺失会明确保留，工作日迟到重跑不计正式盘前成绩，历史记录与显式历史回放保留。

### 主页面

- **开始运行**：选择模型和方法版本，启动或恢复批次，查看真实进度。
- **修改版本**：将方法复制为本地草稿，修改模块、校验，然后由用户明确分享或下载团队版本。
- **查看结果**：查看冻结报告、决策、官方方向标签、分钟回放、虚拟账户和受控运行对照。

连接、数据、团队同步和软件更新以聚焦弹窗打开，不作为新的主页面。原始证据、模型调用、凭据、结果和虚拟账户保留在本机。

## 两个内置方法

- **独立证据门禁版 · 正式基准**：要求适用领域同向、至少两个未冲突的独立根，同时有市场／行业背景和个股证据，且没有独立反向根；最多发布三个方向，最终门禁由确定性代码执行。
- **跨域综合研判版 · Shadow**：根据该版本已校验的领域报告和反方意见，增加综合步骤，对照主要机制、最强反方、未知项、失效条件和其他候选。两版使用同一份冻结证据，但报告不必相同；代码仍校验引用、完整性和发布上限。

这些标签表示研究角色，不表示已证明的性能。一次批次或任何历史回放都不能证明任一方法更好。

## 如何保持可比

```text
时点股票池 + 截止时间前的数据源
                    ↓
       一份冻结证据快照
                    ↓
 六个隔离领域 + 不投票的反方审查
                    ↓
   所选方法的经校验决策规则
                    ↓
  本地记录 → 事后标签与分钟回放
```

每条保存的运行都记录方法快照、模型配置哈希、证据哈希、候选集合、交易规则身份和日期。缺少身份时会显示「未记录」，不会假设相同。八个研究 Skills 覆盖编排、市场冲击、经济关系、原始事件、资本流、衍生品、价量结构与反方完整性审查；角色与来源摘要见[研究与对照设计](docs/research-design.md)。

# 盘前分析与结果展示

研究工作台使用 `sealed-evidence-before-market-open-v1` 时间规则：

- 证据不晚于美东08:50冻结；分析期间不补入新数据。
- 结果必须在NYSE常规盘开盘前完成；09:30整及之后完成的结果仅供参考。
- 节假日、交易日期和夏令时由交易所日历判断。
- 旧预测、模型输出和原时间戳不改写。按新时间规则重新评价的历史记录保存原资格、当前资格及规则标识，默认结果页只显示简洁状态；不能声称新规则事先已注册。

每日结果按“日期＋版本＋运行记录”分组。勾选整组进行比较；股票行只展示该股票的方向、开收涨跌和净盈亏，整组标题单独显示当日合计及余额。缺失一只股票行情不会隐藏其他股票的已知结果；整日未完成时不虚构完整余额。

默认开仓仍使用09:31分钟。个别历史记录只有经过用户明确授权，才可使用有原始观测支持的替代分钟。例外记录绑定原预测哈希、批次、版本、日期和股票，保留真实替代时间及事后授权标记，不成为自动回退规则，也不改变其他股票的已保存股数。带例外的回放不能当作相同成交条件下的方法对照。

历史回放成交保持原股数；已启用余额连续继承时，界面累计余额按兼容账户历史净盈亏衔接，不重新用今天的余额给旧交易定仓。

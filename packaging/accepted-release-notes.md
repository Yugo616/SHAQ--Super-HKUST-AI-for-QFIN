0.7.8：余额与运行恢复修复。Windows、Mac Apple Silicon 和 Intel 使用同一源码版本。

- 重新核对价格时，保留上次已结算的余额、当日盈亏和单股结果，不再突然变成“—”。临时数据库锁冲突会有界重试。
- 当日进度只显示当天任务及确实在运行的任务。旧的失败任务保留在历史恢复入口，不删除原记录。
- 修复今天运行时旧任务又显示成“运行中”的问题。
- 点击继续分析后立即显示恢复进度，同一批次不再重复显示旧失败与新进度。成功调用继续复用。
- 分析失败显示简短中文原因与下一步，原始诊断仍保存。
- 窗口在空闲时也能发现后台新启动的任务；总进度按已校验的任务计数，完成后停止动画。
- 行情与账户更新失败单独说明，不再让已经完成的研究看起来像模型失败。
- 支持经明确核实的本机型号归属校正：同一模型原来记作默认值时可延续原余额，不改冻结预测和历史成交。
- 未选定具体型号的旧连接会提示选择；已选模型保持不变。
- Windows 使用支持中文路径的系统接口修复已有的本应用快捷方式，不依赖固定用户名。

不改变两种方法、预测门槛、账户规则、费用或冻结预测。不修改 versions 分支，不上传每日数据。

# SHAQ Daily Oracle Lab 0.6.0 · macOS 内部测试版

只下载适合自己芯片的一个 DMG：**Apple-Silicon** 用于 M 系列，**Intel** 用于 Intel 芯片。要求 macOS 15 或以上。

打开 DMG，将 App 复制到应用程序目录。无需安装 Python、Git 或 Zipline。

连接模型 → 登录团队 GitHub → 勾选「独立证据门禁版 · 正式基准」和「跨域综合研判版 · Shadow」→ 批量运行 → 查看分析及各自虚拟账户。

研究模式不连接券商。初始资金 $10,000，每票最多 $1,000；09:31 ET 分钟开价进入、收盘前五分钟的分钟开价退出，双边手续费和不利滑点各 0.05%。这是统一假设下的收盘后模拟回放，不是实际成交；缺失分钟不猜价，独立复核后才累计。旧记录只读保留。

Codex／Claude Code 使用本机已安装工具的登录态，也可连接 OpenAI、Anthropic 或兼容 API。WorkBuddy 仅通过兼容 API 接入。

两个平台均通过原生构建、安装、双方法 Zipline 样例、三个页面、恢复及卸载检查；模型调用使用固定样例，不代表所有个人模型账户均实测。源码 `84dc32c4901ccadab53372ee526186d44786d83c`；[完整验收记录](https://github.com/Yugo616/SHAQ--Super-HKUST-AI-for-QFIN/actions/runs/34486634455)。
